# CodeAlpha – JPG File Organizer

## Project Description
A Python automation project that automatically organizes JPG images by moving them from a source folder into a destination folder.

## Features
- Automatically identifies JPG files.
- Creates source and destination folders.
- Moves JPG images using Python.
- Leaves other file types untouched.
- Prevents overwriting files with duplicate names.
- Displays the total number of images moved.

## Technologies Used
- Python
- OS module
- Shutil module
- File handling

## How to Run
1. Open the project folder in VS Code.
2. Open main.py.
3. Place JPG images inside the Source_Images folder.
4. Open the VS Code terminal.
5. Run `python main.py`.
6. Find the organized images inside Organized_Images.

## Testing
The project is tested for JPG detection, empty folders, non-JPG files, automatic folder creation and duplicate filenames.
